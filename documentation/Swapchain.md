The swapchain is a hardware extension we enable through the logical device. The swapchain basically is a manager of images which are just the data ready to be displayed. If we only had one image buffer, we had to wait for the image to finish being displayed before starting to work on the next one. This wastes precious GPU uptime. Having more image views, we can let the GPU work on the next image while the current image completes the display, and once its done, the next image is most likely ready to go. To help manage and avoid corruption in image data, we manage timings using semaphores and fences. Fences stop the CPU from sending new command buffers to the image view if there is still data being processed. CPU to GPU syncronization. And semaphores stop the GPU from working in an imageview if its currently being displayed. GPU to GPU syncronization.
