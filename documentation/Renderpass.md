If we gave instructions to the GPU on what to do with each image, we would be wasting precious time in a repetitive task. Thats where renderpass comes in. Renderpass is a contract given to the GPU that describes the attachments, the types of outputs the rendering process will write to. For flux we set the color and depth attachments. For the flags we have loadOp set to VK_ATTACHMENT_LOAD_OP_CLEAR, which basically means that we clear the last frame before rendering the new one. For store in storeOp we have VK_ATTACHMENT_STORE_OP_DONT_CARE for the depth and VK_ATTACHMENT_STORE_OP_STORE for the color. Since depth data is only used to determine what is in front of what, once we are done using it we can discard it. For the color we store it since we want to send it to the swapchain for display.
