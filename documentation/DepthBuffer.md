When rendering the frame, we only want parts that are on direct sight of the camera, things that are occluded have to be discarded. Thats where the depth buffer comes in. For each of all the pixels of the window we have potential candidates called fragments. Each fragment has a depth value or how far they are from the camera. The GPU decides between these fragments which one is the final pixel, so we bind the depth buffer to the attachment of the depth buffer and send it to the GPU for rendering. The depth buffer is then discarded and the final pixel is saved in the color attachment ready to be sent to the swapchain to be displayed.
