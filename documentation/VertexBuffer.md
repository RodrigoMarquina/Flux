The vertex buffer is a chunk of active memory where we store the data of our geometry and vertices. This buffer is the bridge between our game logic and the GPU architecture. This data is sent to the GPU for rendering and stays in VRAM for as long as the geometry exists.
Its important to mention that the CPU cant directly upload data to the VRAM, we need a middleman, thats where the staging buffer comes in. Once at startup the we create this buffer that lives in mapped memory where both the CPU can write to and the GPU can read from and that creates the bridge between the CPU and VRAM.
